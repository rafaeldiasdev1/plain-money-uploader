Privacy Policy

Last updated: November 17, 2026

Plain Money Uploader ("the tool") is an internal tool operated by the owner of the YouTube channel Plain Money Explained. It is used only to manage that one channel.

Data the tool accesses

With the channel owner's authorization through Google OAuth, the tool uses the YouTube Data API to upload videos, set video metadata (title, description, tags, thumbnail, publish time) and read the channel's own video list to confirm uploads.

How data is used and stored

The tool does not collect, sell or share personal data of any viewer or other user. The only stored credential is the OAuth token for the owner's own channel, kept privately by the owner and used solely for the actions above. Video files and metadata belong to the channel owner.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using YouTube features through the tool, the channel owner is also bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions.
